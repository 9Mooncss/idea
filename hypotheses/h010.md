# H010: Жеребьёвка по текущей оценке силы точнее голландской

**Формулировка.** Если перед каждым туром оценивать силу игроков по всем партиям (модель Эло с учётом стартового рейтинга) и сводить ближайших по этой оценке, доля турниров с правильным победителем вырастет хотя бы на 5 процентных пунктов по сравнению с голландской системой.

**Как проверяем.** Сравнение «адаптивной» жеребьёвки и голландской при одинаковом числе туров; победитель определяется обычным образом (очки, BH-C1).

**Что опровергнет.** Если прирост меньше 5 п.п.

## Новизна (веб-поиск)
Идея адаптивной жеребьёвки по байесовской оценке известна: Glickman & Jensen (2005), «Adaptive paired comparison design» (https://repository.upenn.edu/handle/20.500.14332/47978). Наш вариант — упрощённый.

## Результат проверки
**Опровергнута, причём сильно.** Адаптивная жеребьёвка даёт 36% правильных победителей против 46% у голландской, тау 0,31 против 0,74. Вероятная причина: равные соперники с первых туров дают мало информации, а очки у всех выравниваются. Файл: experiments/results/h010.txt.
