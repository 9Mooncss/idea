# H003: Модель силы по всем партиям лучше, чем очки + тай-брейк

**Формулировка.** Если расставить всех игроков по оценке силы из модели Брэдли–Терри/Эло по всем сыгранным партиям (не глядя на очки), итоговая таблица будет точнее отражать настоящую силу, чем таблица «очки, затем BH-C1».

**Как проверяем.** Считаем коэффициент Кендалла (мера совпадения двух порядков, 1 = полное совпадение) между таблицей и настоящей силой, а также долю турниров, где первое место занял настоящий сильнейший.

**Что опровергнет.** Если тау Кендалла у модели не выше, чем у таблицы по очкам.

## Новизна (веб-поиск)
Близкая идея известна: Csató, «Ranking by pairwise comparisons for Swiss-system tournaments» (arXiv 1508.06773) — предлагает ранжировать по попарным сравнениям (метод наименьших квадратов) вместо очков; проверял на реальных олимпиадах, без «настоящей силы». → «частично известна».

## Результат проверки
**Опровергнута** (в обычных условиях). Модель БТ без рейтинга даёт то же тау Кендалла, что и «очки + BH-C1» (0,7373 против 0,7371) и не больше правильных победителей. Лишь при очень шумных рейтингах небольшой выигрыш (0,727 против 0,717). Зато модель, учитывающая стартовый рейтинг, сильно лучше (0,84; правильный победитель 67% против 47%) — но в основном за счёт рейтинга: один только стартовый рейтинг даёт 0,815.
