# H013: Лига чемпионов: критерий «очки соперников» помогает более слабым

**Формулировка.** В новом формате Лиги чемпионов (36 команд, 8 матчей, по 2 соперника из каждой корзины) критерий №6 при равенстве («сумма очков соперников») чаще ставит выше более слабую из двух команд, потому что команда не играет сама с собой: у сильных из 1-й корзины соперники из своей корзины чуть слабее, у слабых из 4-й — чуть сильнее.

**Как проверяем.** Симуляция жеребьёвки и матчей (голы по Пуассону). Для пар команд с равными очками смотрим, ставит ли критерий выше настоящую сильнейшую.

**Что опровергнет.** Если согласие ≥ 50%.

## Новизна (веб-поиск)
Близкая работа: Csató и др., «Ranking matters: Does the new format select the best teams…» (arXiv 2503.13569) — о силе расписания в новом формате ЛЧ. Именно критерий №6 там, судя по выдаче, отдельно не разбирался.

## Результат проверки
**Опровергнута.** Критерий «очки соперников» чаще ставит выше *сильнейшую* команду: 57,8% [57,7–58,0], 100 000 сезонов, 14,4 млн матчей. Средняя сила соперников одинакова для всех корзин (–0,0082 для каждой): эффект «команда не играет сама с собой» ничтожен. А сам критерий решает границы 8/9 и 24/25 лишь в 0,05–0,09% сезонов.
