# H001: Средний рейтинг соперников лучше Бухгольца-минус-1

**Формулировка.** Среди игроков с равными очками тай-брейк «средний рейтинг соперников» (ARO) чаще ставит выше настоящего сильнейшего, чем «Бухгольц с отсечением худшего» (BH-C1, первый тай-брейк FIDE по умолчанию).

**Как проверяем.** Симуляция 2000 турниров в 6 разных настройках (число игроков, туров, шум рейтинга, доля ничьих). Для каждой пары игроков с равными очками смотрим, совпал ли порядок по тай-брейку с порядком по настоящей силе («согласие», %).

**Что опровергнет.** Если в большинстве настроек согласие ARO не выше согласия BH-C1 (с учётом погрешности).

## Новизна (веб-поиск)
Похожая работа существует: Ito, Ahara, «Evaluation of Tiebreak Systems in Swiss-System Tournament», Game Programming Workshop 2023 (IPSJ), https://ipsj.ixsq.nii.ac.jp/records/229358 — оценивает известные тай-брейки симуляцией. Полный текст открыть не удалось (сеть закрыта), поэтому неизвестно, сравнивали ли они ARO. Точного совпадения не найдено → «частично известна».

## Результат проверки
**Опровергнута.** ARO (средний рейтинг соперников) хуже BH-C1 во всех 7 настройках: например, базовая 63,5% против 66,1%; шумные рейтинги 60,4% против 65,7% (погрешность ±0,2). Побочное наблюдение: лучшим турнирным тай-брейком везде оказалась «прогрессивная сумма» (Progressive, 67–71%), лучше любого Бухгольца. Файл: experiments/results/h001.txt.
