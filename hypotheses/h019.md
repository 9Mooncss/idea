# H019: Киберспорт CS2: жеребьёвка Valve по Бухгольцу вредит сильнейшим

**Формулировка.** Правило Valve (внутри группы с одинаковым счётом сортировать по Бухгольцу, затем по посеву) пропускает в плей-офф меньше настоящих топ-8 команд, чем сортировка только по посеву.

**Как проверяем.** Симуляция швейцарской стадии Major (16 команд, до 3 побед/3 поражений, решающие матчи Bo3).

**Что опровергнет.** Если разница в среднем числе настоящих топ-8 среди прошедших < 0,05 или в пользу Бухгольца.

## Новизна (веб-поиск)
Количественной оценки «Бухгольц против посева» не нашёл. Есть критика формата (dust2.us, substack «CS2's Swiss System: A Broken Format?», пост Graham Pitt 2023 — без проверки) и много симуляторов для предсказаний Pick'Em, которые реализуют правила Valve (например, github.com/SmallRob/CS2_Major_Swiss), но не сравнивают их с альтернативой. Valve в 2024 сменила первый тур (1–9 вместо 1–16) — комментаторы связывали это с перекосом из-за Бухгольца.

## Результат проверки
**Подтверждена.** Точная реализация правил Valve (официальный регламент с GitHub, редакция 07.10.2026) против той же системы без Бухгольца (только посев). За стадию проходят в среднем на 0,21–0,29 меньше настоящих топ-8 команд (±0,015; 20 000 стадий на сценарий). Сильнейшая команда вылетает в 2,7% случаев против 1,5%. Проверка устойчивости: чем точнее посев, тем больше вред (до −0,45). При случайном посеве разницы нет (+0,01 ± 0,02). То есть Бухгольц нигде не помогает выбрать сильных.
