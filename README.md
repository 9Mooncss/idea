# Поиск проверяемых гипотез: швейцарская система в шахматах

Здесь ИИ-ассистент ищет гипотезы, которые можно проверить дешёвой компьютерной симуляцией.
Тема: какие правила шахматного турнира по швейцарской системе (дополнительные показатели при равенстве очков — «тай-брейки», правила жеребьёвки, подсчёт очков) лучше отражают настоящую силу игроков.
Мы генерируем виртуальных игроков с известной «настоящей» силой, разыгрываем тысячи турниров и смотрим, какие правила чаще ставят сильнейшего выше.

- `reports/tema.md` — почему выбрана эта тема.
- `hypotheses/` — гипотезы (одна на файл).
- `experiments/` — код (`python3 experiments/hNNN.py`) и результаты (`experiments/results/`).
- `critiques/` — скептический разбор каждой гипотезы.
- `reports/` — сводки партий; `log.md` — журнал работы.
